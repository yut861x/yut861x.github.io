1.两数之和

发表于 2025-09-24 更新于 2025-09-28 分类于 牛马の日常

#题目链接
https://leetcode.cn/problems/two-sum/description/?source=vscode

说起两数之和，如雷贯耳，与之相比的只有四六级词汇的abandon大帝，乃至code界的hello，world！我每年都会刷他，或许每年只刷他！

两数之和：都这么说了，我还说什么呢？兄弟，我自己解了！

代码块（高亮显示）：

// @lc code=start
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        for(int i = 0; i < nums.size(); i++)
        {
            for(int ii = i+1; ii<nums.size(); ii++)
            {
                if(nums[i]+nums[ii]==target)
                {
                    return {i,ii};
                }
            }
        }
        return {};
    }
};
// @lc code=end
